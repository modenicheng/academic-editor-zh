# 中文学术语体

## 目标

中文学术写作首先要求准确、清楚、连贯，其次才是修辞。优先用动词说明研究者、系统、实验或数据实际做了什么。

## 常见问题

### 名词化过度

不佳：本文进行了对模型性能的系统性评估。

改：本文系统评估模型性能。

不佳：该机制对结果产生了显著影响。

改：该机制显著影响结果。

### 长前置定语

不佳：本文提出了一种面向多来源异构生物医学数据自动获取与验证的可扩展代理框架。

若信息过密，改为：本文提出一套代理方法，用于自动获取并验证多来源异构生物医学数据。该方法支持扩展到新的数据源。

### 被动堆叠

不佳：数据被解析后被送入验证模块，并被进一步标记为可发布状态。

改：系统解析数据后执行验证；通过验证的数据进入发布阶段。

保留被动的情况：施事不重要、受事必须突出，或领域惯例明确要求时。

### 机械连接词

“此外、同时、因此、然而、值得注意的是、具体而言”若只承担段落装饰，删除。逻辑关系确实需要显式标明时保留。

### 防御性写作

不佳：需要强调的是，本文并不试图证明该方法在所有场景下均优于现有方法。

改：本文验证范围限于……；结果仅支持……。

把边界写成可核验条件，而不是向评审预先辩解。

### 贡献表述

不佳：本研究具有重要理论意义和广阔应用前景。

改：直接写新增方法、数据、实验或发现，并指出对应证据位置。

## 从 humanizer-yu 借鉴但需收紧的原则

- 能用直接动词时，不用“进行/作出/产生 + 名词”。
- 多层“的”常提示结构过载，但不要机械删除必要定语。
- 西式被动和名词化结构常让中文变硬，但学术语境允许必要被动。
- 删除无信息量套话、宣传腔、模糊归因和公式化展望。
- 不强求成语。论文准确性高于文学节奏。
